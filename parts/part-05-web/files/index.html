Enterprise Linux Server Management & Monitoring System

This RHEL administration lab demonstrates local identity and access controls, LVM/XFS storage, optional NFS, scheduled backup and restore, and read-only host health reporting.

Operations

This static page is a project overview; it does not show live system metrics. Administrators should use the documented runbooks and inspect the health report locally on the server.
